# RAG … in the Browser!

## RAG … in the Browser!

Turso recently announced  ...  Turso in the Browser

It brings full power of SQLite directly to your web applications via WebAssembly.

It also brings full native vector search

You can load up hundreds of documents… and still return results at sub 50 ms

and did we mention… this is all … in the browser!

So you could ... say... pre-embed your entire docs package 

and make it available locally ....

Well… that’s exactly what we did with **voweldocs**

But wait… we leveled up even one step further… 

we now inject the graded results of our Turso browser RAG

… into the context of the vowel conversational **voice AI client**

So now you can have an **intelligent conversational discussion**… with our docs!

Wow… sounds cool!

How do I check that out?

Go to [docs.vowel.to](https://docs.vowel.to)

Click the Turso RAG debug button in the lower left corner of the docs

That will open the Turso RAG debug panel. 

One tab shows all the markdown documents pre-embedded in our RAG. 

The other tab shows a test chat input, that returned scored relevance results

Try it out by typing in a question for our docs ... 
and the watch it return document exercts with various grades

## What about conversational voice?

While your on docs.vowel.to 

click the voweldocs button  in the nav bar

This will open the Vowel API key config

There are tabs for SaaS or … self-hosted API keys

Enter a valid key from you vowel subscription or selfhosted instance 

Once your key is validated ,you will see Vowel mic button appear in the lower right corner

Click on the mic button, an you’re ready to start dialoguing with voweldocs.
