# vowel-components — UI mock style

## Style prompt

Dark productivity UI: slate chrome, crisp borders, vowel-adjacent blue accents. Reads as real app chrome without copying any single product pixel-perfect.

## Colors

| Role | Hex | Use |
|------|-----|-----|
| Canvas | `#0f1419` | App background |
| Panel | `#1a2332` | Sidebars, cards |
| Border | `#2d3a4f` | Dividers |
| Text primary | `#e6edf3` | Labels, titles |
| Text muted | `#8b9cb3` | Secondary |
| Accent (voweldocs) | `#2563eb` | Primary actions, links |
| FAB inactive | `#6b7280` | Voice idle |
| FAB active | `#22c55e` | Session on |
| FAB user | `#3b82f6` | User speaking |
| FAB think | `#eab308` | Processing |
| FAB AI | `#a855f7` | Assistant voice |

## Typography

- UI: **DM Sans**, 500/600
- Code: **JetBrains Mono**, 400/500

## What NOT to do

- Generic pure `#333` on `#fff` “bootstrap” look
- Rainbow code without hierarchy
- Illegible microcopy on hero titles
